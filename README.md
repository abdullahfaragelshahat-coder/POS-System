# 👑 GoldStore POS & Inventory Management System

منظومة "الذهبي" الاحترافية لإدارة المبيعات، الفواتير السريعة، وجرد المخازن. تم بناء هذا النظام كحل متكامل يخدم أصحاب المحلات التجارية لإدارة أعمالهم وحماية بياناتهم المالية من خلال نظام صلاحيات صارم.

---

## ✨ مميزات المنظومة (Key Features)

### 1. نظام الصلاحيات والأدوار (Role-Based Access Control - RBAC)
* **المدير (Admin):** يمتلك كامل الصلاحيات؛ يمكنه استعراض الأرباح وإجمالي المبيعات، الاطلاع على التقارير الحساسة، إضافة منتجات جديدة للمخزن، أو حذف وتعديل المنتجات الحالية.
* **الكاشير (Cashier):** يمتلك صلاحيات محدودة؛ يمكنه فقط استخدام شاشة البيع السريع واستخراج الفواتير وعرض كميات المخزن المتاحة، وتم حجب لوحة التحكم وأزرار الإضافة والحذف عنه تماماً لأمان النظام.

### 2. شاشة المبيعات والفواتير السريعة (`sales.php`)
* واجهة بيع ذكية تتيح للكاشير اختيار المنتج وتحديد الكمية.
* خصم تلقائي ولحظي للكميات من المخزن بمجرد إتمام عملية البيع.
* جدول تفصيلي يعرض آخر 10 فواتير صادرة مع حساب الإجمالي ووقت العملية بدقة.

### 3. إدارة وجرد المخزن (`products.php`)
* عرض كامل للبضائع المتاحة، أسعارها، والكميات المتبقية.
* نظام ديناميكي يخفي ويظهر أزرار (الإضافة / التعديل / الحذف) تلقائياً بناءً على هوية المستخدم المسجل.

### 4. التقرير المالي اليومي والطباعة (`daily_report.php`)
* شاشة مخصصة للمدير لحساب "تأفيل الوردية" ومعرفة دخل درج النقدية لليوم الحالي فقط.
* ميزة الطباعة الورقية بضغطة زر **(🖨️ طباعة التقرير)** حيث تم تنسيق الصفحة برمجياً لإخفاء القوائم والأزرار غير الضرورية عند الطباعة لتظهر كشيت حسابات رسمي.

---

## 🛠️ التكنولوجيات المستخدمة (Technologies Used)

* **Backend:** PHP (OOP / PDO Architecture) لضمان حماية النظام من ثغرات الـ SQL Injection.
* **Database:** MySQL (Relational Database).
* **Frontend:** HTML5, CSS3 (تصميم كلاسيكي ذهبي متناسق ومريح للعين).
* **Session Management:** لتأمين الصفحات والتحقق من هوية المستخدمين.

## 🚀 طريقة التشغيل والتركيب (Installation)

1. قم بتحميل المشروع ووضعه داخل مجلد الـ `htdocs` الخاص ببرنامج **XAMPP**.
2. افتح الـ **phpMyAdmin** وقم بإنشاء قاعدة بيانات جديدة باسم `store_db`.
3. قم باستيراد (Import) الجداول الخاصة بالمشروع أو تنفيذ الأكواد التالية في تبويب **SQL**:
   * جدول المنتجات `products`.
   * جدول الفواتير والمبيعات `sales` & `sale_items`.
   * جدول المستخدمين `users`.
